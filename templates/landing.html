01 /BUBBLE ENGINE

八种气泡，语气由分镜自己挑

分镜阶段模型会给每句对白选一种语气，出图时后端按这份语气把对应形状的气泡与中文字体画进页面。 你也可以在分镜管理或气泡编辑器里随时逐格切换。

01 贴入小说

先给它一段故事

几千字一章就行。它会按情节切页，每页两到八格，标注镜头语言，并顺手把出场角色挑出来。

一天清晨，lcy 睁开了惺忪的睡眼，立即感受到了身体的疲惫与不适。

“哎呦，早知道就不冲牢大的战力了。”可发出的只有一声喵喵喵。

02 定角色

每个人先有一张人设

角色先出人设图（或手动上传参考图），之后每一页都拿它当基准，脸部与服装不会一页一个样。

03 出整页

整页一次出图

一次性生成整页网格分镜，气泡由本地按坐标精准叠上去，不满意还能直接拖动微调位置。

03 /REVERSE WORKFLOW

漫画也能读成小说

把画好的漫画页或扫描页丢进去，视觉模型逐页读出画面、对白和旁白，按顺序拼成一篇连贯可编辑的小说正文。

逐页识别
一次支持多张批量上传，按上传顺序排好，逐页识别画面细节与气泡里的对白文字。
上下文连成故事
处理下一页时会自动携带上一页剧情上下文，保证人称、情节与节奏前后衔接不断。
对白自然入文
台词与动作描写自然融入第三人称小说正文，而不是生硬的逐格看图说话罗列。
一键复制与导出
结果自动留存在会话里，页数多也不会丢，支持一键复制到剪贴板或下载为 .txt。

04 /LOCAL FIRST

接口自带，数据留在本机

程序不绑定任何一家模型服务。填上你自己的接口地址和 Key，生成出来的图片、分镜与写作都安静地存在本机目录里。

config.local.json LOCAL CONFIG
// 节选，不含敏感密钥
{
  "llm_model": "deepseek-chat",
  "img_model": "doubao-seedream-4-5-251128",
  "comic_mode": "bw",
  "bubble_render_mode": "pil",
  "reference_strength": 0.75,
  "segments_per_page": 0
}

黑白还是彩色、气泡走本地 PIL 还是交给模型，都清晰地写在这一份配置里。

01 · OPEN PROTOCOL

任意 OpenAI 格式接口

文本与图像分两个地址填写，豆包、DeepSeek、MiniMax、OpenAI 等都能接，配置页里可一键测通。

02 · CREDENTIAL SAFETY

凭据不进代码仓库

管理员密码写在 .env，首次启动随机生成；API Key 只存在本机配置文件里，不上传任何第三方。

03 · LOCAL CACHE

参考图本地复用

角色人设图自动缓存复用，同一个角色连续生成多页不必反复上传下载。

04 · MULTI-ACCOUNT

按账号独立存档

每个账号独立目录存放作品状态、图片与写作历史，互不干扰，也可一键公开分享或整体备份。
