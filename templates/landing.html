把一段小说， 变成一页漫画

贴入小说，自动分镜、配人设、出整页。中文对白由本机字体画进画面，不会变成方块。

智能分镜 角色一致 整页出图 中文对白本地渲染 八种语气气泡 漫画读回小说 作品历史 自带 API 接口

八种气泡，语气由分镜自己挑

分镜阶段模型会给每句对白选一种语气，出图时后端按这份语气把对应形状的气泡画进页面。 这是它支持的八种形状，你也能在分镜管理里逐格改。

贴入小说

先给它一段故事

几千字一章就行。它会按情节切页，每页两到八格，并顺手把出场角色挑出来。

一天清晨，lcy睁开了惺忪的睡眼，立即感受到了身体的疲惫与不适。

“哎呦，早知道就不冲牢大的战力了。”可发出的只有一声喵喵喵。

定角色

每个人先有一张人设

角色先出人设图，之后每一页都拿它当参考图，脸部与服装不会一页一个样。

出整页

整页一次出图

一次性生成整页分镜，气泡由本地按坐标叠上去，位置还能拖。

漫画也能读成小说

把画好的页面丢回去，视觉模型逐页读出画面、对白和旁白，再按页拼成一篇可编辑的小说。

逐页识别
一次最多 50 张，按上传顺序排好，逐页读画面与气泡里的字。
连成故事
处理下一页时会带上上一页的结果，前后衔接不断。
对白入文
台词写进正文，用第三人称叙述还原画面，而不是逐格罗列。
导出文本
结果按页存好，页数多也不会丢，可一键复制或下载 txt。

本地运行

接口自带，数据留在本机

程序不绑定任何一家模型服务。填上你自己的接口地址和 Key，生成出来的图片、分镜与写作都存在本机目录里。

// config.local.json (节选, 不含密钥)
{
  "llm_model": "deepseek-chat",
  "img_model": "doubao-seedream-4-5-251128",
  "comic_mode": "bw",
  "bubble_render_mode": "pil",
  "reference_strength": 0.75,
  "segments_per_page": 0
}

黑白还是彩色、气泡走本地还是交给模型，都写在这一份配置里。

任意 OpenAI 格式接口

文本与图像分两个地址填，豆包、DeepSeek、MiniMax 这类都能接，配置页里能一键测试。

凭据不进代码

管理员密码写在 .env，首次启动随机生成；API Key 只存在本机配置文件里。

参考图本地缓存

人设图缓存成 base64 复用，同一个角色第二次生成不必重新下载。

按账号分开存

每个账号一个目录，作品状态、图片、写作历史互不干扰，可整体备份。
